# Changelog

All notable changes to this project will be documented in this file.

This project follows a simple versioning approach based on conceptual and structural updates to the framework specification.

## [0.1.0] - 2026-04-07

### Added
- Initial release of **AI Structural Philosophy Academic Framework v0.1**
- Core thesis defining AI as a structured system understood through:
  - internal structure
  - behavioral generation
  - value configuration
  - safety profile
  - societal implementation
- Formal academic positioning of **AI Structural Philosophy** as a unified field connecting:
  - interpretability
  - alignment
  - ethics
  - safety
  - governance
- Human-readable `README.md` draft
- YAML specification draft for the academic framework
- Core definitions for:
  - internal structure
  - posture
  - value direction
  - emotion-related representation
  - persona
  - structural drift
  - structural safety
  - internal causality
  - causal trace
- Six foundational axioms:
  - Structural Primacy
  - Directional Causality
  - Persona Variability
  - Structural Value Embedding
  - Internal Safety Requirement
  - Causal Accountability
- Seven major framework chapters:
  - Internal Structural Theory
  - Behavioral Generation Theory
  - Value and Ethical Structure Theory
  - Structural Steering Theory
  - Persona Selection Theory
  - Structural Safety Theory
  - Societal Implementation Theory
- Core concept list and methodology framework
- Validation principles and falsifiability conditions
- Initial roadmap from `v0.1` to `v1.0`
- `CITATION.cff` metadata for citation and attribution
- GitHub repository description and topics set

### Notes
- Version `0.1.0` is the **first public draft** of the framework.
- This release establishes the conceptual and structural foundation of the project.
- Future versions may refine terminology, add evaluation metrics, formalize experiment templates, and extend institutional implementation details.
